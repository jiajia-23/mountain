## Windows 本地运行

不要直接双击 HTML 文件运行。请在本目录打开 PowerShell，执行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/千里江山图.html`。首次运行需要等待 Three.js、MediaPipe 脚本和手势模型从 CDN 加载完成，并在浏览器提示时允许摄像头权限。页面状态会显示模型加载、请将手放入镜头区域或手势控制中。

如果摄像头没有画面，检查浏览器地址栏的摄像头权限，并确认没有其他程序独占摄像头；也可以用 `http://127.0.0.1:8000/千里江山图.html` 重试。
