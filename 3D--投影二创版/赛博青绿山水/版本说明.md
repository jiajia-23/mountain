# 千里 · 青绿流光

第三轮：改为六组不对称峰峦和断续岩层纹理，移除横向扫描线。河道宽度沿水程变化，源头抬高为两段跌水，近景展开为宽水面；另建顺流方向的曲线和 11000 个随水程运动的飞沫粒子。保留晨昏控制与原版手势识别。属于艺术化程序水流，未做真实流体求解。

从 `3D--main` 原版重新复制的独立副本。修改仅在本目录的千里江山图.html；同目录其他 HTML 保留原样。

山体采用青蓝粒子与连续山形线，局部黄绿色光脉；水面采用青紫流线和移动黄绿高光。没有把参考图片贴成背景。

原版 MediaPipe 段逐字保留：手腕到中指尖的距离控制 targetScale，保持原来的映射、缓动与待机逻辑。新增 H 切换面板、C 切换镜头窗口、F 切换全屏。

运行：在仓库根目录执行 `python -m http.server 8014 --bind 127.0.0.1`，打开 `http://127.0.0.1:8014/3D--投影二创版/赛博青绿山水/千里江山图.html`。

第二轮更新：增加写入深度的不透明山体底层，解决山体线条穿透；基于地形坡度计算法线，太阳方位改变时分别更新各朝向山坡的明暗。渐变天空、太阳光晕、薄云、三层远山和距离雾色共用晨昏参数。水面加入随太阳移动的反射色，配色扩展为翡翠青绿、蓝紫与黄绿。

新增“日照时刻”滑杆和自动晨昏开关。拖动滑杆暂停自动播放；勾选开关继续循环。循环约 140 秒。日照控制独立于原来的手势输入。相机随山高略抬升，减少张手后山峰被画面上沿截断。

验证：JavaScript 语法检查通过；原版 MediaPipe 与手势实现逐字对比一致；浏览器实际检查白昼及暮色画面，拖动滑杆后自动播放停止，未发现页面着色器错误。模型已加载并显示“请将手放入镜头区域”，未进行真实手掌操作测试。未实现投射阴影、镜头景深模糊或参考图中完整的大尺度旋涡；层次感来自几何遮挡、远山和空气透视。
