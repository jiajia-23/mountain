# 3D-粒子交互 / 投影二创版

本目录是原项目的独立二创副本，原始版本位于上级目录 `3D--main`，不会被本版本修改。

当前方向是“云海日出 / Moss Horizon”：借鉴千里江山图的散点山脊、宋画的留白和日出时的暖色雾光，用较少、较宽的粒子线条适配墙体投影。张开手掌会抬高山体、增强日光和云海扩散，握紧手掌则回到安静的远山剪影。

## 投影设计原则

- 使用深蓝底、靛青远山和一条暖色日光带，减少室内杂光下的颜色损失。
- 太阳和雾光使用低亮度色块，不依赖大量粒子，避免投影出现闪烁噪点。
- 粒子数量从 35 万降到 18 万，线条数量减少但山脊仍保留层次。
- 暂时保留原 UI 和摄像头调试窗口，便于现场调试；正式投影前再增加隐藏调试面板和无 UI 模式。

## Windows 本地运行

在本目录打开 PowerShell：

```powershell
python -m http.server 8000
```

打开 `http://localhost:8000/千里江山图.html`，允许摄像头权限，等待模型加载后用单手张合测试。

## 方案实验场

新增 [方案实验场.html](./方案实验场.html)，这是与原粒子山水完全分离的四种低频光影原型：

- **苔藓呼吸场**：暗绿色呼吸光、菌丝线和漂浮孢子，模拟实体苔藓向墙面生长。
- **一分钟的山**：山体剪影在一段时间内经历晨昏变化，手势控制光线强弱。
- **墙体是一扇窗口**：把投影区域当作窗口，手势控制窗外云雾和观看方向。
- **云是一种生物**：一团缓慢呼吸、会跟随手势偏移的半透明云体。

实验场使用 Canvas 2D，不依赖 Three.js 粒子系统；支持 MediaPipe 单手输入，也支持鼠标移动和点击切换。按 `H` 隐藏面板，按 `C` 显示摄像头预览。运行本地服务器后访问：

```text
http://localhost:8001/方案实验场.html
```

## 苔藓天气计划

新增 [苔藓天气计划.html](./苔藓天气计划.html)，这是在“苔藓呼吸场”基础上的完整视觉原型。它以 Olafur Eliasson 的《The Weather Project》所代表的沉浸式光场、雾与身体感为启发，但不复制原作图像：把巨大公共空间中的太阳转译为苔藓内部一枚湿润的光核，并加入十层雾海、根系光脉和漂浮孢子。

它更适合后续做成正式投影版本：暗部占比高、主光源明确、运动低频，手势控制光场中心与强度。访问：

```text
http://localhost:8001/苔藓天气计划.html
```

## 借一束光，唤醒山谷

新增 [借一束光唤醒山谷.html](./借一束光唤醒山谷.html)，这是按“靠近、聚拢、抬手、停留、余晖”的完整动作叙事制作的投影原型：

- 人出现后，山后先出现一小片微光；
- 张开手掌，微光向手的位置聚拢；
- 抬手，太阳从实体山峰后方升起；
- 远山、山谷光带和树影逐层显现；
- 停留约 3.5 秒后，云层打开并进入完整山谷日出；
- 手放下后保留余晖，不立即清零。

它使用低频 Canvas 图形和 MediaPipe 手势，不依赖原来的粒子山水。鼠标移动可模拟手的位置，便于无摄像头时演示。

## 雪峰第一束光：静态关键帧板

新增 [雪峰第一束光-关键帧板.html](./雪峰第一束光-关键帧板.html)。这一页暂时不接手势和声音，只验证同一构图的三个视觉状态：

1. **未被照亮**：冷灰峰群、深暗谷地和清楚的主峰体积。
2. **第一束光**：最高山脊先获得暖金色迎光面，太阳不必直接出现。
3. **完整高潮**：主峰、支脉、远峰和局部云海建立完整层次，但谷底仍保留暗部。

侧栏同时标注了未来可用的实现方式：山体轮廓、迎光面、谷底暗部和云海都可以通过预制图层与遮罩合成，适合有限算力的墙面投影。打开：

## Windows 本地运行

不要直接双击 HTML 文件运行。请在本目录打开 PowerShell，执行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/千里江山图.html`。首次运行需要等待 Three.js、MediaPipe 脚本和手势模型从 CDN 加载完成，并在浏览器提示时允许摄像头权限。页面状态会显示模型加载、请将手放入镜头区域或手势控制中。

如果摄像头没有画面，检查浏览器地址栏的摄像头权限，并确认没有其他程序独占摄像头；也可以用 `http://127.0.0.1:8000/千里江山图.html` 重试。
